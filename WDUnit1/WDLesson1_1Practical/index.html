Web Technologies

HTML

HTML stands for HyperText Markup Language and is the standard language used to create webpages.
It acts as the backbone of a website, similar to the skeleton of a building.
By using special tags, it tells your web browser where to put text, images, and links on a screen.

  1. Heading
  2. Paragraph
  3. Lists
  4. Links
  5. Colors

CSS

CSS (Cascading Style Sheets) is the code used to design and style how a webpage looks.
While HTML builds the basic structure and text of a website, CSS is what adds colors, fonts, layouts, and animations.
Think of HTML as the skeleton of a house and CSS as the paint, furniture, and decorations.

  • Syntax
  • Borders
  • Icons
  • Tables
  • Margins

Javascript

JavaScript is a programming language used to make web pages interactive and dynamic.
While HTML builds the structure and CSS adds the styling, JavaScript makes things happen like pop-up menus, animations, and responding to clicks.
It runs directly inside web browsers and on servers to bring static websites to life.

  1. Loop
  2. Timers
  3. Arrays
  4. Maps
  5. Functions

ReactJS

React JS is a popular tool used by programmers to build the visible parts of websites.
It allows developers to create reusable building blocks, like buttons or search bars, so they do not have to rewrite code from scratch.
This makes websites run much faster and feel smoother when you click around.
